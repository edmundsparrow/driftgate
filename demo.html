What just happened

The dog never learns a rule about gates. It just keeps attempting to move. Every attempt calls driftGate(dogPosition, gatePosition, bounds) — the same primitive from driftGate.js, unmodified. It measures the signed distance between where the dog is and where the boundary sits, then classifies it as ok, resist, or jam.

drift = position − boundary → driftGate() → ok / resist / jam → enforcement

When the gate is closed, the bounds passed into driftGate() put maxHard right at the boundary — so the dog gets a resist warning as it nears the gate, then a hard jam at the line. Open the gate and nothing about the dog changes — no new reasoning, no new rule learned. Only the bounds object handed to driftGate() changes, and the exact same attempted move now reads ok well past where it used to jam. Nothing about the agent changed. The capability boundary did.

One thing in this demo is deliberately not part of driftGate(): click Make Uncertain and the system escalates instead of guessing. driftGate() only ever returns ok, resist, or jam — it has no concept of "ask a human." That's an application-layer decision built on top of the primitive, which is exactly the point: the gate primitive stays small and dumb, and the surrounding system decides what any given state should trigger.
